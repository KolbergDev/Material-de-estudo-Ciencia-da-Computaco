O que é Hypertext Markup Language (HTML)?

HTML é a linguagem de marcação padrão usada para criar e e struturar páginas web.
Ela não é uma linguagem de programação (não tem lógica, variáveis ou cálculos),
mas sim uma linguagem de marcação, que usa tags (como <h1>, <p>, <div>) para
definir a estrutura e o significado do conteúdo de uma página, como títulos, parágrafos, links,
imagens e tabelas.

Como e porquê surgiu o HTML?

O HTML foi criado por Tim Berners-Lee, um cientista britânico que trabalhava no CERN
(Organização Europeia para a Pesquisa Nuclear), entre 1989 e 1991.
Ele precisava de uma forma de compartilhar e conectar documentos de pesquisa entre cientistas
de diferentes lugares do mundo de maneira fácil e padronizada.

A ideia surgiu do conceito de hipertexto (textos interligados por links), combinado com um sistema de marcação chamado
SGML (Standard Generalized Markup Language), que já existia. Assim nasceu o HTML: uma linguagem simples que permitia
criar documentos com links, formatação básica e estrutura, acessíveis através de um navegador.
Essa invenção foi a base para a criação da própria World Wide Web (WWW).

O que é eXtensible Hypertext Markup Language (XHTML)?

XHTML é uma reformulação do HTML seguindo as regras rígidas do XML. Ele foi criado no
início dos anos 2000 pelo W3C (World Wide Web Consortium) com o objetivo de tornar o HTML
mais estrito, organizado e padronizado, corrigindo a "bagunça" que muitas páginas HTML tinham
na época (tags mal fechadas, erros de sintaxe tolerados, etc.).

Qual a diferença de XHTML para HTML?

No HTML, as tags podem ficar sem fechar (ex: <p>texto), não há diferença entre maiúsculas
e minúsculas (<DIV> é igual a <div>) e os atributos podem não ter aspas. Já no XHTML, todas as
tags devem ser fechadas (ex: <p>texto</p>), devem ser escritas em minúsculas e os atributos
sempre precisam de aspas (class="titulo"). Ou seja, o XHTML segue todas as regras de sintaxe do
XML, enquanto o HTML é bem mais flexível e tolerante a erros.


Hoje em dia o HTML5 (versão atual) já incorporou boas práticas do XHTML, mas manteve a
flexibilidade do HTML original, e o uso do XHTML puro caiu bastante.

O que é eXtensible Markup Language (XML)?

XML é uma linguagem de marcação criada para armazenar e transportar dados de forma
estruturada, organizada e independente de plataforma. Diferente do HTML, o XML não tem tags pré-definidas,
o próprio usuário cria as tags que fizerem sentido para os dados que está representando.
É muito usado para troca de dados entre sistemas diferentes, como APIs, arquivos
de configuração e integração entre softwares.

Qual a diferença de HTML para XML ?

O HTML serve para exibir dados e conteúdo visualmente numa página, usando tags pré-definidas
(<h1>, <p>, <table>) com significado fixo, sendo focado na apresentação de como o conteúdo
aparece no navegador. Já o XML serve para armazenar e transportar dados, com tags criadas pelo
próprio usuário, sem significado fixo, sendo focado na estrutura e no conteúdo dos dados em si.

Em resumo: o HTML mostra informação para humanos lerem numa página, enquanto o XML
organiza informação para sistemas e computadores trocarem dados entre si.
